# 🏏 Cricket Analytics Dashboard

A data-driven dashboard that provides insights into cricket matches, players, and venues using real match data and machine learning.

---

🎯 Project Objective

To analyze ball-by-ball cricket data and build an interactive dashboard that:

- Visualizes player and team performances
- Predicts match outcomes using machine learning
- Provides dynamic insights based on venue, toss, and form
